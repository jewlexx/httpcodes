# HTTP Codes

HTTP status code helpers.

## Installation

```bash
npm i --save httpcodes
```

## Usage

```ts
import { HttpCode } from "httpcodes";

console.log(HttpCode.Ok); // 200

// Or with a constant

import { consts } from "httpcodes";

console.log(consts.OK); // 200
```
